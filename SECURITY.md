# Security policy

Please report vulnerabilities through GitHub's private security reporting for this repository. Do not include real school messages, PDFs, cookies, passwords, second-factor codes, or keychain entries in a public issue or pull request.

Supported scope: the current macOS local-stdio version. Authentication uses a user-driven Chrome sign-in and a session in the macOS login keychain. There is no hosted service or official EduPage OAuth integration. Access to other accounts or arbitrary URLs is outside the intended tool contract.
